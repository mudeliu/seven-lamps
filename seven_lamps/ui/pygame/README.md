# Pygame 图形界面 (v0.5)

## 启动方式

```bash
# 方式1：命令行参数
python seven_lamps/main.py --pygame

# 方式2：直接运行模块
cd seven_lamps/ui/pygame
python __init__.py

# 方式3：代码调用
from seven_lamps.ui.pygame import PygameUI
ui = PygameUI()
ui.run()
```

## 文件结构

```
pygame/
├── __init__.py      # 模块入口，PygameUI包装类
├── assets.py        # 颜色、字体、布局常量
├── renderer.py      # 渲染器（绘制面板、手牌、灯等）
├── game_app.py      # 主应用（游戏循环、事件、场景）
└── README.md        # 本文件
```

## 操作说明

| 操作 | 按键/鼠标 |
|------|----------|
| 选择手牌 | 点击 或 数字键 1-7 |

## 动画效果

| 动画 | 触发时机 | 效果 |
|------|----------|------|
| 卡牌飞行 | 出牌时 | 卡牌从手牌飞向中央，带缩放+淡出 |
| 灯数闪烁 | 灯数变化时 | 大号±数字，绿色(加)/红色(减)，向上飘动 |
| 文字弹出 | 效果结算、奥秘触发 | 效果文字向上飘动+淡出 |
| 粒子爆发 | 胜利、关键效果 | 金色粒子向四周散开 |

## 音效列表

| 音效 | 触发时机 | 说明 |
|------|----------|------|
| play_card | 出牌 | 清脆方波短音 |
| draw | 抽牌 | 正弦滑音 |
| lamp_up | 加灯 | 523Hz上升音 |
| lamp_down | 减灯 | 330Hz锯齿波音 |
| mystery | 奥秘触发 | 三和弦神秘音 |
| victory | 胜利 | 大三和弦延长音 |
| response_place | 放入响应区 | 中音确认音 |
| turn_start | 回合开始 | 高频提示音 |
| error | 无效操作 | 低沉错误音 |

按 `M` 键可开关音效。

## 已知限制

1. **无守夜人职业** — PVE固定为燃灯者 vs 灭灯者
2. **AI简化** — AI每回合只出一张牌（即使决胜回合可出两张）
3. **无背景音乐** — 仅有事件音效
4. **无录像回放** — 动画是实时生成的
